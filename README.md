# FIN 410: Financial Statement Analysis of Robi Axiata Ltd.

## Executive Summary
This project presents an end-to-end financial analysis of **Robi Axiata Ltd.** covering the multi-year financial trends from 2020 through 2025. 
The model evaluates profitability expansion, working capital dynamics, solvency structure, market valuation multiples, 
and a comprehensive 5-Way DuPont Analysis of Return on Equity (ROE).

## Project Structure
The financial model contains the following key sheets:
* **Balance Sheet & Income Statement:** Historical financial statements (in BDT and BDT '000).
* **Common Size Analysis (CSA):** Vertical common-size balance sheet and income statement.
* **Activity & Liquidity Ratios:** Working capital turnover, Cash Conversion Cycle (CCC), and defensive interval ratios.
* **Profitability & Solvency Analysis:** Profit margins, Return on Assets (ROA), Return on Capital, leverage, and interest coverage ratios.
* **Valuation Multiples:** Range analysis of Price-to-Earnings (P/E), Price-to-Book (P/B), and Price-to-Sales (P/S).
* **DuPont Analysis:** 5-step decomposition of Return on Equity (ROE).

## Key Financial Insights
* **ROE Growth:** ROE expanded significantly from 2.36% in 2020 to 13.41% in 2025, primarily driven by improvements in net profit margins and reduced tax burdens.
* **Operating Efficiency:** Operating margins expanded from 13.92% (2020) to a peak of 21.95% (2024), reflecting improved cost management and operating leverage.
* **Capital Structure:** De-leveraging trend observed in interest-bearing debt,
* dropping total debt to near-zero levels by 2025 while maintaining consistent interest coverage above 2.7x.
